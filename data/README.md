# Datos

- **Fuente:** datos simulados con fines didácticos, provistos por la cátedra
  (TP de Correlación y Regresión, archivo `EstudioPresionEdad (1).csv`).
- **Adaptación:** `mediciones.csv` y `mediciones.json` contienen las mismas
  mediciones; se agregó un código por paciente y 8 registros con errores para
  ejercitar la validación.
- **Unidad de análisis:** cada fila es un paciente adulto con una medición.
- **Variables:** `codigo`, `edad` (años), `imc` (kg/m²),
  `presion_sistolica` (mmHg) y `grupo` (`A`: control, `B`: intervención).
- **Limitaciones:** datos simulados; 50 pacientes válidos; criterio de
  hipertensión simplificado. Los 8 registros adicionales contienen errores.
